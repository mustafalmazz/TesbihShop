# TesbihShop

A modern, responsive, and elegant e-commerce frontend application built with React and Vite, specifically designed for selling premium rosaries (tesbih).

## Features
- **Responsive Design**: Fully optimized for mobile and desktop devices with a premium aesthetic.
- **Dynamic Product Gallery**: Interactive image sliders and a zoomable lightbox for detailed product viewing.
- **Shopping Cart**: Real-time cart management.
- **Direct Checkout**: Quick order functionality seamlessly integrated with WhatsApp.
- **Modern UI**: Clean, minimalistic interface with smooth micro-animations.

## Tech Stack
- React 19
- Vite
- Lucide React (Icons)
- Vanilla CSS

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
